# Changelog

All notable changes to Vulta will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.2.0] - 2026-02-19

### Added

- **Onboarding tutorial** — first-launch spotlight overlay that walks new users through the app step by step (6 steps covering Home, Mixdowns, Drop Zones, Yearly Goal)
- **Help tab** — in-app user guide with collapsible accordion sections for each feature (Getting Started, Drop Zones, Mixdowns, Yearly Goal & Heatmap, Settings)
- Onboarding completion state persisted in settings so it only shows once

## [0.1.0] - 2026-02-18

### Added

- Initial release
- **Drop zones** — drag audio files onto Instrumental or Lyrics & Melody zones
- **Auto-organization** — files sorted into dated `Idea Gen - {date}/{zone}/` folders with collision handling
- **Mixdowns panel** — watch DAW export folders, copy or move renders into the idea library
- **Contribution heatmap** — GitHub-style 30-day activity grid
- **Yearly goal** — click-to-edit target with live progress bar
- **Launch on startup** — optional autostart toggle
- MIT license and README with logo
